# v13：主循环 unroll 2 —— 让 ptxas 跨迭代交错 ldsm/mma（全形状正向，小形状 +10%）

> **接力链**：v12 后小形状仍落后 cuBLAS（公平协议 512³ = 71%）→ v12.md 两端 roofline 解剖：512³ = 填充 67%（pow2 tile 天花板）× 每 SM 效率 34.6% × 写回 -15.6%，1024³ = 流水固定成本 -41.5% 主导（去同步消融 82.5 > cuBLAS 65.4，计算核已领先 26%，缺口全在摊薄）→ 本版动作 = NVRTC JIT 探针（autogemm/nvjet 同款能力）证明「全展开跨迭代调度」是最大可及项 → phase 算术化证伪锁定机制 → 单行 `#pragma unroll 2` 免 JIT 复现 → 实测（测量协议 v2 公平口径）= 512³ **+10.3%**，1024³/2048³/4096³/8192³ 全部 **+0.9–2.1%（三轮全正，零回归）**。
>
> 本版同时产出**测量协议 v2**（DVFS 爬升偏差 + 干扰深坑的三层噪声模型，已写入 criterion.md 5.1.1）——v13 的全部数字按新协议重裁。

---

## Step 1 — 瓶颈定位与假设来源

v12.md 两端 roofline 消融表已把小形状缺口解剖为：

| 尺寸 | 缺口构成 | 可及性 |
|---|---|---|
| 512³ | 填充 67% × 每 SM 效率 34.6% × 写回 -15.6% | 填充需非 2 幂 tile（JIT 专属）；每 SM 效率受 tile 结构限制 |
| 1024³ | 流水固定成本 -41.5% 主导（16 个 K 块摊薄极差） | 3-stage/BK=32 已证伪；剩「编译期形状特化」未测 |

假设：cuBLAS 的 nvjet 引擎靠 JIT 做形状特化（引擎地图实证），若 NVRTC 把 M/N/K 烘焙进编译期（常量折叠边界检查 + 主循环首尾 peeling），可收窄固定成本项。这是 autogemm 路线的第 1 步（收益测量），非 2 幂 tile 是第 2 步。

## Step 2 — 探针链（4 段，一段证伪一段假设）

### 探针 ⑦a：NVRTC JIT 形状特化（`bench/probe_jit.cu` + `bench/jit_kernel.cu`）✅ 基础设施可行

设备代码与 v12 逐行同源，仅 4 处适配：M/N/K 由 `-D` 烘焙为 constexpr；tensor map 改按指针传（host 侧 `cuTensorMapEncodeTiled` 产物拷到 device 全局内存）；配置经 `-DUSE_SMALL` 注入（`extern "C"` 符号便于 `cuModuleGetFunction`）；`min`/`make_float2` 本地化。NVRTC 编译 240–364ms 出 CUBIN 直载，精度与 v12 逐位一致。

**踩坑 3 个**：NVRTC 需显式 `-I/usr/local/cuda/include`（不自动找 `cuda_bf16.h`）；无标准 C++ 头（`cstdint` 不可用，自定义定宽类型，且 NVRTC 不预定义 `__NVRTC__`，需探针显式传 `-DJIT_NVRTC`）；`umin` 与 nvcc 的 `math_functions.hpp` 撞名（双路编译需改名）。

**实测（3 轮交替）**：

| 尺寸 | v12（运行时参数） | JIT（形状烘焙） | Δ |
|---|---|---|---|
| 512³ | 26.18（均值） | 30.75 | **+17.5%** |
| 1024³ | 58.25 | 57.92 | -0.6%（持平） |
| 2048³ | 78.17 | 78.44 | +0.3%（持平） |

**增益只出现在 K≤8 块的形状**（512³ = 8 块）。SASS 资源对比：REG 88→78、STACK 16B→0——编译器对 8 次迭代做了**全展开**。

### 探针 ⑦b：phase 数组算术化（`bench/probe_phase.cu`）——证伪 ❌

**假设**：全展开的收益来自 phase 数组（`phase[2]`/`prod_empty_phase[2]` 是 16B local memory 动态索引）被消解。
**改动**：2-stage 下相位确定性交替，消费者 `phase = (kb>>1)&1`、生产者按 kb 奇偶推导，数组全删（REG 81 / STACK 0）。
**实测**：全尺寸持平（4032³ 干净形状 +0.9%）；4096³ 曾现 "+5%" 复测为 2 幂病理噪声窗口（下一批变为 -2%）。
**结论**：收益**不是** phase 索引本身，而是**展开后 ptxas 的跨迭代调度视野**——下一迭代的 ldsm 被提前塞进当前 mma 链的空档。相位算术化本身无收益，方向关闭。

### 探针 ⑦c：`#pragma unroll 2/4`（`bench/probe_unr2/4.cu`）——免 JIT 复现 ✅

| 尺寸 | unroll2 | unroll4 |
|---|---|---|
| 512³ | **+14.3%** | +7.2% |
| 1024³ | +2.8% | +0.5% |
| 2048³ | +1.4% | +2.4% |
| 8192³ | +1.0%（两轮稳定） | +0.9% |

unroll2 全面优于 unroll4（小形状目标优先），且 4096³ 一次 "-17.6%" 读数复测为病理离群点（90.90/89.29 vs 88.53/90.92，持平）。**一行 pragma 拿到 JIT 全展开收益的大部分，零基础设施成本**。

### 探针 ⑦d：测量协议审计（`bench/probe_warm.cu` / `probe_warm13.cu` + `cublas_bench.cu` 修复）——协议 v2 诞生

背景：v13 裁决中发现 4096³/8192³ 出现 -16 至 -24% 深坑、512³ 散布 ±5.6%。审计结论（三层噪声模型，全文见 criterion.md 5.1.1）：

1. **DVFS 爬升偏差（系统性）**：空闲 208MHz → 满频 3003MHz，ms 级爬升。旧协议 3 次热身后，小形状整个计时区（512³ 十迭代约 100μs）落在爬升内 → 历史小形状绝对值系统性偏低约 6%。证据：热身 3→3000 次，512³ 基线 26.4→27.9–28.4（+5.7%），散布 ±5.6%→±1.3%；8192³ 首发深坑（78.5）长热身后 4/4 消失；
2. **干扰深坑（外部）**：长热身后仍偶发 -30 至 -40% 单发深坑，时间相关、打到谁随机。**误并发实锤**：两个 benchmark 进程并行时 2048³ 从 77 崩到 35–55（-55%）——桌面统一内存环境下并发 GPU 负载即深坑机制；
3. **4096³ 2 幂病理**（已知）：±5% 方差叠加。

**关键反向发现**：cuBLAS 基线一直是稳态口径——nvjet 首调自带 JIT 编译（上百 ms）天然完成热身（修复后的 cublas_bench 512³ 长/短热身均 38.0，±0.4%）。历史「512³ 差 cuBLAS 30%」实为偏高，公平口径 v12 = 71%。

**双协议分离**（已入 criterion）：稳态协议（长热身 ≥30ms + ≥5 轮中位数，用于版本判定）与冷调用协议（短热身，用于突发/边缘场景用户体验）分列报告，禁止混用——生产 serving 持续忙 + 启动 warmup，稳态即真实；GB10 突发稀疏负载才咬爬升。

**顺带修复**：cublas_bench 原不支持命令行参数（跑硬编码形状表，无 512）；早前三方对照中 "cuBLAS: 16 TFLOPS" 是 grep 误匹配表头 "BF16 TFLOPS" 的垃圾值（未进结论）。

## Step 3 — 实现

`gemm_v13.cu` 与 `gemm_v12.cu` 的唯一功能差异（一行）：

```cpp
    // ---- 主循环（零 __syncthreads，BK=64 分 2 个 pair 处理）----
    // v13：unroll 2 让 ptxas 跨迭代交错 ldsm/mma（短 K 摊薄差的形状收益最大，长 K 无回归）。
    #pragma unroll 2
    for (int kb = 0; kb < num_k_blocks; ++kb) {
```

寄存器：BigCfg 190+16B stack → 192+0；SmallCfg 88+16B → 87+0。占空不变（1 block/SM）。

## Step 4 — 验证

**精度（8 形状全 PASS，`max_rel_err = 0` 或 1e-6 级）**：512³、1024³、2048³、8192³、512×4096×2048（跨分派边界）、1024×512×520（奇数 K 块）、1000³（非 2 幂）、256³。

**性能（测量协议 v2：长热身 + 顺序执行 + 3 轮交替中位数 + 同会话）**：

| 尺寸 | v12 中位数 | v13 中位数 | Δ | cuBLAS（公平协议） | v13/cuBLAS |
|---|---|---|---|---|---|
| 512³ | 26.97 | **29.77** | **+10.3%** | 38.03 | 78.3% |
| 1024³ | 57.67 | 58.21 | +0.9% | 65.38 | 89.0% |
| 2048³ | 77.09 | 78.68 | +2.1% | 95.73 | 82.2% |
| 4096³ | 85.66 | 86.71 | +1.2% | 83.14* | 104.3% |
| 8192³ | 93.86 | 95.04 | +1.3% | 99.01 | 96.0% |

*4096³ cuBLAS 当日 83.14 为 2 幂病理方差日（历史区间 83–97）。

1024³/2048³/4096³/8192³ 均为 **3/3 轮正向**（非中位数侥幸）。冷调用口径（短热身）：512³ v12 ≈ 26.4 / v13 ≈ 28.3–29.6。

## JIT 路线归档（autogemm 剩余价值，基础设施已验证）

- **全展开（JIT 专属，K≤8 块）**：512³ 仍领先 unroll2 约 +4–6%（JIT 30.75 vs v13 短热身 29.0–29.6）——多出的部分来自 8 次迭代完整展开（unroll2 只配对）；
- **非 2 幂 tile**（64×104 → 512³ 填充 67%→83%）：只能 JIT 做，v12.md 已论证为 nvjet 优势的来源；
- NVRTC 编译 240–364ms/形状、精度逐位一致、`probe_jit.cu` 全套可复用——若重启 autogemm，第 1 步已完成，只差磁盘缓存与分派集成。

## 学习要点

1. **形状特化的收益不在「常量折叠」而在「展开后的调度器视野」**——phase 算术化证伪把这一点钉死：同样的寄存器/stack 改善（88+16B→81+0）性能纹丝不动，跨迭代指令交错才是本体；
2. **unroll 是免 JIT 的 80% 解**：一行 pragma 拿到 JIT 全展开 17.5% 中的 10.3%，且中大形状附带 +1%；
3. **测量协议本身可以成为最大的系统性噪声源**：DVFS 偏差曾把所有小形状绝对值压低约 6%——协议审计的 ROI 高于任何单项 kernel 优化；
4. **同协议 A/B 的 delta 对协议缺陷免疫**（偏差两边对称抵消），但绝对值与基线对比会失真——这解释了为什么 v0→v12 轨迹依然成立而「差 cuBLAS 百分比」需要修正。

## 局限与下一步

- 512³ 剩余缺口 21.7%：填充 67% 为主，需 JIT 非 2 幂 tile（归档待重启）；
- 1024³ 剩余 11%、2048³ 剩余 17.8%：流水固定成本 + 每 SM 效率，CUTLASS 式多项小改动叠加（BK=32+cp.async+NamedBarrier），已论证改动量等于重写半个 kernel；
- 8192³ 剩余 4%：写回串行暴露（persistent 重叠已三层证伪）；
- **FP8 路线（235.79 TFLOPS = 2× BF16 峰值）仍为最后一个天花板级方向**。
