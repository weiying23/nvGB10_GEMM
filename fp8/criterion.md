## 2. FP8 特有增量规则

### 2.1 精度验证（FP8 的参照系与门限）

FP8 是**精度换速度**的路线，验证方法分两步：

1. **参照系**（阶段 C 探针裁决）：
   - 若 cuBLASLt 在 GB10 有 FP8 引擎 → 同精度对照；
   - 若无 → **两段对拍**：(a) 先量化-反量化跑 BF16 cuBLAS，得"FP8 固有量化误差"基线；(b) 我方 FP8 结果与 (a) 的差值才是"实现误差"，门限看这个差值；
2. **门限**（初值，阶段 A–C 后可修订）：per-tensor e4m3 对 [-1,1] 均匀数据的固有相对误差量级为 1e-2（尾数 3 位）——实现误差应不放大它（vs 参照系在固有误差量级内一致）；
3. **量化误差与实现误差禁止混谈**：报告里必须分开列（"固有量化误差"与"实现增量误差"两行）。

### 2.2 基线标定（FP8 线自己的标尺，勿用 BF16 的）

| 标定项 | 值 | 状态 |
|---|---|---|
| FP8 峰值 | 235.79 TFLOPS | 已测（bench_micro） |
| Roofline 转折点 | 235.79 / 255.6 ≈ 922 FLOP/byte | 推导值 |
| cuBLAS(Lt) FP8 基线 | 待测（阶段 C） | 可能为空（无引擎） |
| FP8 量化 kernel 带宽 | 待测（阶段 B） | — |

**关键预判（阶段 D 验证）**：FP8 的 A/B 搬运字节减半，但带宽不变（255.6 GB/s）——若瓶颈在搬运（大 K），收益 < 2×；若瓶颈在计算（我们的 8192³ 计算核 113.5 已贴近 BF16 墙 118），才有接近 2× 的空间。**先 roofline 后动手**。

### 2.3 阶段门（每阶段一个判定点，不过门不进下阶段）

- **阶段 A（布局探针）**：单 mma 16×32×8 vs CPU **逐位一致**（用 e4m3 精确可表示的小整数构造数据，f32 累加精确）→ 布局锁死；
- **阶段 B（量化 kernel）**：量化-反量化往返 = 恒等（对 e4m3 精确值），带宽 ≥ 200 GB/s；
- **阶段 C（参照系探针）**：cuBLASLt 有/无 FP8 引擎，记录实测结论（无论有无都是产出）；
- **阶段 D（GEMM v1）**：per-tensor scale 版全尺寸精度过门 + 性能 ≥ BF16 v13 同形状的 1.3×（低于此则记录"GB10 FP8 不成立"的实测结论并归档）。

- 源码/报告在 `fp8/` 与 `reports/fp8_*.md`，命名带 `fp8_` 前缀；
- 版号独立（fp8_v1, fp8_v2...），不与 BF16 线互占；
